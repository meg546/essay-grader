Create src/lib/pdf-extract.ts with an async function `extractTextFromPdf(file: File): Promise<string>`:

1. Configure pdfjs-dist worker at module level:
   ```typescript
   import * as pdfjsLib from "pdfjs-dist";

   pdfjsLib.GlobalWorkerOptions.workerSrc = new URL(
     "pdfjs-dist/build/pdf.worker.min.mjs",
     import.meta.url
   ).toString();
   ```

2. Implement extractTextFromPdf:
   - Read file as ArrayBuffer via `file.arrayBuffer()`
   - Load PDF via `pdfjsLib.getDocument({ data: arrayBuffer }).promise`
   - Iterate pages 1 to pdf.numPages
   - For each page: `page.getTextContent()` then map `content.items` extracting `.str` and joining with space
   - Join all page texts with double newline
   - If extracted text is empty or whitespace-only after all pages, return empty string (caller will handle the empty case with a user message)

3. Export the function as a named export.

Note: If the `new URL(import.meta.url)` worker pattern fails during Vite build, the fallback is CDN: `pdfjsLib.GlobalWorkerOptions.workerSrc = "https://cdnjs.cloudflare.com/ajax/libs/pdf.js/5.5.207/pdf.worker.min.mjs"` (see Open Question 1 in research).
