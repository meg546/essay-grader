  <action>
Create src/components/grading/EssayInput.tsx. This is a self-contained component that reads/writes essayText from the Zustand store.

**Structure:**
- Wrap in a Card with CardHeader ("Your Essay") and CardContent
- Inside CardContent: textarea wrapper div, upload button, counts display

**Textarea with drag-and-drop:**
- Use shadcn Textarea, controlled by `useAppStore(s => s.essayText)` and `setEssayText`
- Fixed height: `h-64` with `resize-none` and `overflow-y-auto`
- Placeholder: "Paste your essay here or drag and drop a file..."
- Wrap the Textarea in a `<div>` that handles dragover/dragleave/drop events
- On drag-over: add a visual border highlight (e.g., `ring-2 ring-primary border-primary` classes) using `isDragOver` state
- Handle the dragleave flickering pitfall: use a drag counter (increment on dragenter, decrement on dragleave, show overlay when counter > 0, reset to 0 on drop). This avoids the child element flickering issue (Pitfall 2 from research).
- On drop: check file extension. If not .txt or .pdf, call `toast.error("Only .txt and .pdf files are supported")` and return. For .txt: `file.text()` then `setEssayText(text)`. For .pdf: call `extractTextFromPdf(file)` then `setEssayText(text)`. If PDF extraction returns empty string, call `toast.error("Could not extract text from this PDF. Try pasting the text directly.")`.

**File upload button:**
- Below the textarea, a small outline Button with Upload icon: "Upload File"
- Hidden `<input type="file" accept=".txt,.pdf">` triggered by button click via ref
- onChange handler: same logic as drop handler (check extension, read file, set text)

**Word and character counts:**
- Below the upload button, display as small muted text: "{N} words . {M} characters"
- Derive from essayText: `wordCount = text.trim() ? text.trim().split(/\s+/).length : 0` (guards against empty string returning 1 -- Pitfall 4 from research)
- `charCount = text.length`
- Format with toLocaleString for comma separators on large numbers

**User decisions enforced:**
- Counts as small text below textarea (LOCKED)
- No word count limits or warnings (LOCKED)
- Drag and drop on textarea itself, not separate zone (LOCKED)
- Visual feedback on drag-over (LOCKED)
- Toast for unsupported file types (LOCKED)
