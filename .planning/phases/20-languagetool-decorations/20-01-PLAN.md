  <action>
Create `src/api/languagetool.ts`:
- Export `LTMatch` and `LTResponse` interfaces (exact shape from research).
- Export `async function checkText(text: string): Promise<LTMatch[]>`.
- `LT_PUBLIC = 'https://api.languagetool.org/v2/check'` and `LT_PROXY = '/api/languagetool/check'`.
- Send POST with `URLSearchParams({ text, language: 'auto' })` and `Content-Type: application/x-www-form-urlencoded`. Do NOT include `level: 'picky'` — use the default level per research recommendation (Open Question 1).
- First attempt goes to `LT_PUBLIC`. On network/CORS error (catch block), retry once to `LT_PROXY`.
- On HTTP 429: exponential backoff — wait 10s, 20s, 40s across up to 3 retries. Use an internal `_checkText(text, endpoint, retryCount)` helper so the retry logic is clean. After 3 retries, return `[]`.
- On any non-ok response (not 429): return `[]` silently.
- On success: parse JSON as `LTResponse`, return `data.matches`.

Create `backend/app/routes/languagetool.py`:
- `router = APIRouter(tags=["languagetool"])`.
- `@router.post("/languagetool/check")` — reads raw request body, forwards to `https://api.languagetool.org/v2/check` via `httpx.AsyncClient` with 15s timeout and `Content-Type: application/x-www-form-urlencoded`.
- Returns the upstream JSON response directly via `JSONResponse(status_code=res.status_code, content=res.json())`.
- On httpx exception: returns `JSONResponse(status_code=503, content={"matches": []})`.

Update `backend/app/main.py`:
- Add `from .routes import auth, grading, health, history, languagetool` (add languagetool to the existing import).
- Add `api_router.include_router(languagetool.router)` after the history router line.
