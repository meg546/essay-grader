  <action>
Create `src/extensions/LanguageTool.ts` — a Tiptap extension using `Extension.create` + `addProseMirrorPlugins`. This is the most complex file in the phase. Follow the research patterns exactly.

**Extension structure:**

1. Export `const ltPluginKey = new PluginKey<DecorationSet>('languageTool')` — exported so Phase 21/22 can read decoration state.

2. Export `const LanguageToolExtension = Extension.create({ name: 'languageTool', addProseMirrorPlugins() { ... } })`.

3. Inside `addProseMirrorPlugins`, return a single `new Plugin({...})` with:

**Plugin state (`state.init` / `state.apply`):**
- `init()`: return `DecorationSet.empty`.
- `apply(tr, oldSet)`:
  - If `tr.getMeta(ltPluginKey)` is not undefined, return it (this is the async API result arriving).
  - If `tr.docChanged`:
    - If the new doc is empty (tr.doc.textContent.length === 0), return `DecorationSet.empty` (handles Clear button — Pitfall 6).
    - Find the block node containing the cursor: use `tr.doc.resolve(tr.selection.from)` to get the resolved position, then get the parent block's start/end via `$pos.start()` and `$pos.end()`. Use `$pos.before()` and `$pos.after()` if the resolved pos is at the top level of the block.
    - Remove decorations only in that block range: `oldSet.remove(oldSet.find(blockStart, blockEnd))`.
    - Map remaining decorations: `clearedSet.map(tr.mapping, tr.doc)`.
  - Otherwise return `oldSet`.

**Plugin props:**
- `decorations(state)`: return `ltPluginKey.getState(state)`.

**Debounced check (in the extension's `onCreate` or `onUpdate` lifecycle):**
Use `onUpdate` in the Tiptap extension (NOT the ProseMirror plugin view — use the Tiptap lifecycle):
```typescript
onUpdate({ editor }) {
  clearTimeout(debounceTimer)
  debounceTimer = setTimeout(async () => {
    if (editor.isDestroyed) return
    const text = editor.getText({ blockSeparator: '\n\n' })
    if (!text.trim()) {
      editor.view.dispatch(editor.state.tr.setMeta(ltPluginKey, DecorationSet.empty))
      return
    }
    const matches = await checkText(text)
    if (editor.isDestroyed) return  // check again after await (Pitfall 3)
    const decorations = buildDecorations(editor.state.doc, text, matches)
    editor.view.dispatch(editor.state.tr.setMeta(ltPluginKey, decorations))
  }, 3000)
}
```

Use a module-level `let debounceTimer: ReturnType<typeof setTimeout>` (only one editor instance exists).

**Offset mapping function `buildOffsetMap(doc)`:**
- Walk `doc.descendants((node, pos) => { ... })`.
- For each text node: push `{ charOffset, pmPos: pos }`, then `charOffset += node.text.length`.
- For each block node (after the first text node has been seen): `charOffset += 2` to account for `\n\n` block separator. IMPORTANT: Only add the separator between blocks, not before the first one. Track this with a `seenFirstBlock` flag — skip the charOffset increment for the very first block open.
- Return the array.

**Position lookup function `ltOffsetToPmPos(offset, map)`:**
- Binary search or reverse linear scan the map for the entry where `charOffset <= offset`.
- Return `entry.pmPos + (offset - entry.charOffset)`.

**Decoration building function `buildDecorations(doc, text, matches)`:**
- Call `buildOffsetMap(doc)`.
- For each match in `matches`:
  - Compute `from = ltOffsetToPmPos(match.offset, map)`.
  - Compute `to = ltOffsetToPmPos(match.offset + match.length, map)`.
  - Determine CSS class from `match.rule.issueType`: misspelling/typographical -> `lt-misspelling`, grammar/duplication/inconsistency -> `lt-grammar`, style/locale-violation/register/formatting -> `lt-style`, default -> `lt-grammar`.
  - Create `Decoration.inline(from, to, { class: cssClass, 'data-lt-message': match.message, 'data-lt-replacements': JSON.stringify(match.replacements.map(r => r.value)) })`. Store message and replacements as data attributes so Phase 21's popover can read them without needing to look up the original match object.
- Return `DecorationSet.create(doc, decorations)`.

**Clean up on destroy:**
In the extension's `onDestroy` lifecycle: `clearTimeout(debounceTimer)`.
