<objective>
Fix the EssayUploadModal -> Tiptap editor sync gap: when a user uploads an essay via the toolbar modal, the text must appear in the Tiptap editor DOM (not just in the Zustand store).

Purpose: The one-way sync pattern (editor -> store) means store updates from the modal are invisible to the editor. Without this fix, uploading via the modal silently fails — the text appears saved but is overwritten on the next keystroke.

Output: EssayUploadModal calls a callback that syncs the uploaded text into the Tiptap editor via a new `loadContent` method on EssayInputHandle.
</objective>
