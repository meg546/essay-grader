Add timer fields and actions to the AppState interface:

**New state fields:**
- `timerEndTime: number | null` — absolute epoch ms when timer expires (null = no timer)
- `timerPaused: boolean` — whether timer is paused
- `timerRemainingMs: number | null` — snapshot of remaining ms when paused

**New actions:**
- `startTimer(durationMs: number)` — sets `timerEndTime = Date.now() + durationMs`, `timerPaused = false`, `timerRemainingMs = null`
- `cancelTimer()` — clears all three timer fields to null/false/null
- `pauseTimer()` — snapshots `timerRemainingMs = Math.max(0, timerEndTime - Date.now())`, sets `timerEndTime = null`, `timerPaused = true`
- `resumeTimer()` — recomputes `timerEndTime = Date.now() + timerRemainingMs`, sets `timerPaused = false`, `timerRemainingMs = null`
- `updateTimerDuration(durationMs: number)` — same as `startTimer` (resets endTime to now + duration)

**Persist changes:**
- Bump `version: 3` to `version: 4`
- Add cascading migration block: `if (version < 4) { state.timerEndTime = null; state.timerPaused = false; state.timerRemainingMs = null; }`
- Update `partialize` to include `timerEndTime`, `timerPaused`, `timerRemainingMs`

**useTimer hook** (`src/hooks/useTimer.ts`):

Create a hook that manages the timer lifecycle via setInterval:

1. Read `timerEndTime`, `timerPaused`, `timerRemainingMs` from `useAppStore`
2. Use `useRef` for interval ID
3. `useEffect` on `[timerEndTime, timerPaused]`:
   - If no `timerEndTime` or `timerPaused`: clear interval, return
   - Start `setInterval(1000)` that on each tick:
     - Computes `remaining = timerEndTime - Date.now()`
     - If `remaining <= 0`: call `useAppStore.getState().cancelTimer()` and fire `toast("Time's up!")` via sonner. Use a `firedRef` to ensure toast fires exactly once.
   - Cleanup: clear interval on unmount
4. On mount: check if `timerEndTime < Date.now()` and `!timerPaused` — call `cancelTimer()` immediately WITHOUT toast (expired while tab was closed)
5. Export `remainingMs`: if paused, return `timerRemainingMs`; if running, return `Math.max(0, timerEndTime - Date.now())`; if no timer, return `null`
6. Export `isRunning`: `timerEndTime !== null && !timerPaused`
7. Export `isPaused`: `timerPaused`

Use `useAppStore.getState().cancelTimer()` inside the interval callback (not the selector) to avoid stale closure (Pitfall 1 from RESEARCH.md).

Include a `formatRemainingTime(ms: number): string` helper (exported):
- `totalSeconds = Math.max(0, Math.ceil(ms / 1000))`
- If hours > 0: `h:mm:ss`, else `mm:ss`
- Minutes and seconds zero-padded to 2 digits

**TimerDisplay component** (`src/components/grading/TimerDisplay.tsx`):

1. Call `useTimer()` to get `remainingMs`
2. If `remainingMs === null`: return `null` (no timer active)
3. Render countdown using `formatRemainingTime(remainingMs)`
4. Match WordStats styling: `"flex items-center h-8 bg-muted/50 px-4 text-xs text-muted-foreground transition-colors duration-200 shrink-0"` — but do NOT include `rounded-b-lg` or `border-t` (the parent container will handle that since WordStats and TimerDisplay share a row)
5. Display a Timer icon (from lucide-react) at size `h-3.5 w-3.5` next to the formatted time
6. When remaining < 60 seconds, add `text-destructive` class for urgency
