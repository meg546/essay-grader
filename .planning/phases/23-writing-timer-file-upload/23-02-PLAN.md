**ScrollPicker** (`src/components/grading/ScrollPicker.tsx`):

CSS scroll-snap iOS-style wheel picker for selecting minutes (1-120).

Props: `value: number`, `onChange: (val: number) => void`, `min?: number` (default 1), `max?: number` (default 120), `disabled?: boolean`.

Implementation:
1. Scrollable container with `overflow-y-scroll`, `scroll-snap-type: y mandatory` (use inline style since Tailwind 4 snap classes may not cover all variants), `overscroll-behavior: none`
2. `ITEM_HEIGHT = 36` (matches h-9)
3. Container height = `3 * ITEM_HEIGHT` (108px) — shows 3 visible rows (center highlighted)
4. Padding spacer divs (1x ITEM_HEIGHT) at top and bottom so first/last items can center
5. Each item: `scroll-snap-align: center`, height `ITEM_HEIGHT`, centered text
6. Center item (matching `value`): `font-semibold text-foreground scale-110`
7. Non-center items: `text-muted-foreground/50 scale-90`
8. `useRef` for container element
9. `userScrollingRef` flag to prevent programmatic scroll from fighting user scroll:
   - Set `true` on scroll event
   - Clear after 150ms debounce timeout
10. `scrollToValue(v)` — calls `el.scrollTo({ top: (v - min) * ITEM_HEIGHT, behavior: "smooth" })`
11. `useEffect` syncs scroll position when `value` changes, but ONLY if `!userScrollingRef.current`
12. `onScroll` handler: compute `index = Math.round(scrollTop / ITEM_HEIGHT)`, call `onChange(clamp(index + min, min, max))`
13. Click on item: call `onChange(v)` and `scrollToValue(v)` (unless disabled)
14. Items display the minute value as text, with "min" label on the center item only

**TimerPopover** (`src/components/grading/TimerPopover.tsx`):

Toolbar popover that orchestrates ScrollPicker + presets + start/cancel.

1. Follow TextSizeSelector pattern: `Popover` wraps `Tooltip`, `PopoverTrigger` renders as `TooltipTrigger`
2. Use `Timer` icon from lucide-react (not Clock)
3. Active indicator dot (green) when timer is running or paused: `<span className="absolute top-1.5 right-1.5 w-2 h-2 rounded-full bg-green-500" />` — same pattern as rubric upload dot
4. Controlled `open` state
5. Local state: `selectedMinutes` (default 15) for the picker value before starting

**Two popover modes based on timer state (read `timerEndTime`/`timerPaused` from `useAppStore`):**

**Mode A — No timer running:**
- 4 preset buttons in a row: 15m, 30m, 45m, 1h — clicking a preset scrolls the picker to that value but does NOT auto-start
- ScrollPicker below presets showing `selectedMinutes` with `onChange` updating `selectedMinutes`
- "Start" button: calls `useAppStore.getState().startTimer(selectedMinutes * 60_000)`, then `setOpen(false)`

**Mode B — Timer running or paused:**
- ScrollPicker in disabled/countdown mode: show current remaining minutes (derived from `useTimer().remainingMs`), auto-scrolls every minute
- `userScrollingRef` on the ScrollPicker: if user manually scrolls, pause auto-scroll until "Set" or close
- "Set" button: calls `useAppStore.getState().updateTimerDuration(newMinutes * 60_000)`
- "Cancel" button: calls `useAppStore.getState().cancelTimer()`, closes popover
- If paused: show "Resume" button that calls `useAppStore.getState().resumeTimer()` and closes popover

PopoverContent: `side="left" align="start"` with `w-48` width, padding `p-3`.

**Route-based pause/resume** — add a `useEffect` in GradingPage:
```typescript
const location = useLocation();
const prevPathRef = useRef(location.pathname);

useEffect(() => {
  const wasOnGrade = prevPathRef.current === "/grade";
  const isOnGrade = location.pathname === "/grade";
  const { timerEndTime, timerPaused, pauseTimer, resumeTimer } = useAppStore.getState();

  if (wasOnGrade && !isOnGrade && timerEndTime && !timerPaused) {
    pauseTimer();
  } else if (!wasOnGrade && isOnGrade && timerPaused) {
    resumeTimer();
  }

  prevPathRef.current = location.pathname;
}, [location.pathname]);
```

Note: This useEffect uses `useAppStore.getState()` inside the effect (not selectors) to avoid unnecessary re-renders. The location change is the only trigger.
