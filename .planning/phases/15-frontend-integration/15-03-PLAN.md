  <action>
    **1. Fix Ollama client** (`backend/app/llm/ollama.py`):
    Pass the json_schema to the Ollama OpenAI-compatible endpoint. Ollama supports structured output via the `response_format` field. Change:
    ```python
    "response_format": {"type": "json_object"},
    ```
    to:
    ```python
    "response_format": {
        "type": "json_object",
        "schema": json_schema,
    },
    ```
    This tells Ollama to constrain output to the provided schema. The `schema` key is the Ollama-specific field for structured output enforcement (via its OpenAI-compatible API).

    **2. Fix OpenAI client** (`backend/app/llm/openai.py`):
    Use OpenAI's `json_schema` response format (available in GPT-4o and later). Change:
    ```python
    "response_format": {"type": "json_object"},
    ```
    to:
    ```python
    "response_format": {
        "type": "json_schema",
        "json_schema": {
            "name": "grading_result",
            "schema": json_schema,
            "strict": False,
        },
    },
    ```
    Note: `strict: False` because the schema uses `description` fields and optional properties that strict mode may reject. This still provides strong guidance to the model.

    **3. Fix flat-format normalization** (`backend/app/services/grading.py`, lines 68-83):
    Inside the flat-format normalization loop (after the existing `setdefault` and `improvements` handling, BEFORE `candidate.append(val)`), add normalization for quotes:
    ```python
    # Normalize quotes field -- check alternative key names
    if "quotes" not in val:
        for alt_key in ("highlighted_passages", "evidence_quotes", "evidence"):
            if alt_key in val and isinstance(val[alt_key], list):
                val["quotes"] = val.pop(alt_key)
                break
        else:
            val["quotes"] = []  # Ensure key exists even if empty
    ```

    **4. Add diagnostic logging** (`backend/app/llm/highlights.py`):
    Add a module-level logger. In `compute_highlights`, after reading `quotes = category.get("quotes", [])`, log a warning if quotes is empty:

    ```python
    # Inside compute_highlights, after quotes = category.get("quotes", []):

            "Category '%s' has no quotes -- highlights will be empty for this category",
            category_id,
        )
    ```
