  <action>
1. Run `npm install axios` to add the dependency.

2. Create `src/api/client.ts`:
   - Import axios and useProfileStore (from @/stores/profile-store).
   - Create and export `apiClient = axios.create({ baseURL: "http://localhost:8000/api", timeout: 120_000 })`. Use 120s timeout because LLM grading does two inference passes.
   - Add request interceptor: read `useProfileStore.getState().token`, if truthy set `config.headers.Authorization = "Bearer " + token`. Return config.
   - Add response interceptor: success handler passes through. Error handler checks `axios.isAxiosError(error) && error.response?.status === 401`. If 401: call `useProfileStore.getState().signOut()` then `window.location.href = "/profile"`. Always `return Promise.reject(error)`. Per user decision: silent sign-out on 401, NO toast.

3. Create `src/api/errors.ts`:
   - Import axios.
   - Export function `getErrorMessage(error: unknown): string`.
   - Logic order: (a) if not axios error -> "Something went wrong. Please try again." (b) if `error.code === "ECONNABORTED"` -> "Request timed out. Please try again." (c) if `!error.response` (network error) -> "Could not reach the server." (d) if status 409 -> `error.response.data?.detail || "Conflict."` (for duplicate registration) (e) if status 422 -> extract from `error.response.data?.detail`: if string return it, if array return `detail[0].msg`, else "Invalid input. Please check your data." (f) default -> "Something went wrong. Please try again."

4. Create `src/api/auth.ts`:
   - Import `apiClient` from `./client`.
   - Define local `TokenResponse` interface: `{ access_token: string; token_type: string }`.
   - Export `async function login(email: string, password: string): Promise<TokenResponse>` — POST to "/auth/login" with JSON body `{ email, password }`, return data.
   - Export `async function register(email: string, password: string): Promise<TokenResponse>` — POST to "/auth/register" with JSON body `{ email, password }`, return data.
