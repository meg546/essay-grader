  <files>backend/app/llm/__init__.py, backend/app/llm/client.py, backend/app/llm/ollama.py, backend/app/llm/anthropic.py, backend/app/llm/openai.py</files>
  <action>
1. Create backend/app/llm/__init__.py exporting LLMClient and get_llm_client.

2. Create backend/app/llm/client.py:
   - Define LLMClient as a typing.Protocol with one async method:
     `async def complete(self, system_prompt: str, user_prompt: str, json_schema: dict) -> str`
     Returns raw JSON string from LLM.
   - Define get_llm_client(settings: Settings) -> LLMClient factory using match/case on settings.model_provider.
   - Raise ValueError for unknown provider.

3. Create backend/app/llm/ollama.py - OllamaClient:
   - __init__ takes Settings, creates httpx.AsyncClient with base_url=f"{settings.model_endpoint}/v1", timeout=httpx.Timeout(120.0, connect=10.0).
   - complete() POSTs to /chat/completions with model, messages (system + user), response_format={"type": "json_object"}, temperature=0.3.
   - On httpx.ConnectError or httpx.TimeoutException: retry once, then raise.
   - Extracts response.json()["choices"][0]["message"]["content"].

4. Create backend/app/llm/anthropic.py - AnthropicClient:
   - __init__ takes Settings, creates AsyncAnthropic(api_key=settings.anthropic_api_key).
   - complete() uses client.messages.create with tool_use pattern:
     tools=[{"name": "submit_grading_result", "description": "Submit the grading result", "input_schema": json_schema}],
     tool_choice={"type": "tool", "name": "submit_grading_result"},
     max_tokens=4096, model=settings.model_name, system=system_prompt.
   - Extracts tool_use block input, serializes to JSON string.
   - On anthropic.APIConnectionError or anthropic.APITimeoutError: retry once, then raise.

5. Create backend/app/llm/openai.py - OpenAIClient:
   - __init__ takes Settings, creates AsyncOpenAI(api_key=settings.openai_api_key).
   - complete() uses client.chat.completions.create with response_format={"type": "json_object"}, temperature=0.3.
   - Extracts response.choices[0].message.content.
   - On openai.APIConnectionError or openai.APITimeoutError: retry once, then raise.

All clients store model name from settings.model_name.
  </action>
