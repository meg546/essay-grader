1. Create backend/app/llm/prompts.py:
   - DEFAULT_RUBRIC: A built-in general writing rubric with 4 categories: Thesis & Argument (0-25), Evidence & Support (0-25), Organization & Structure (0-25), Language & Mechanics (0-25). Include clear descriptions for each.
   - build_system_prompt(grade_level: str, rubric_text: str | None) -> str:
     Uses rubric_text if provided, otherwise DEFAULT_RUBRIC.
     Includes grade level context that adjusts expectations (younger = more lenient on vocabulary/citations, college = sophisticated argumentation).
     Instructs LLM to respond with JSON matching the grading schema.
     CRITICAL instruction: "Quote EXACTLY from the essay, character-for-character" for the quotes array.
     The LLM output schema should have categories with "quotes" array (not highlights -- highlights are computed post-inference).
     Each quote object: {"text": "exact quote", "type": "strength"|"improvement", "feedback": "explanation"}.
   - build_user_prompt(essay_text: str) -> str: Wraps essay in clear delimiters.
   - build_grading_schema() -> dict: Returns JSON schema dict for the LLM output format (NOT the final GradingResult schema -- this is the intermediate format with quotes instead of highlights).

2. Create backend/app/llm/highlights.py:
   - find_passage_offset(essay_text: str, quoted_text: str, threshold: float = 0.6) -> tuple[int, int] | None:
     Pass 1: case-insensitive exact match via str.lower().find().
     Pass 2: fuzzy sliding window using difflib.SequenceMatcher. Step = max(1, quote_len // 4).
     Returns (start, end) or None if best_ratio < threshold.
   - compute_highlights(essay_text: str, categories_with_quotes: list[dict]) -> dict[str, list[dict]]:
     Takes the LLM output categories (which have "quotes" arrays) and computes HighlightRange offsets.
     Returns a dict mapping category_id to list of highlight dicts with start, end, category_id, type, feedback.
     Drops any quote that doesn't match above threshold (graceful degradation).

3. Create backend/tests/test_highlights.py with the behavior tests listed above.

2. Create backend/app/services/grading.py - GradingService class:
   - __init__(self, llm_client: LLMClient) stores the client.
   - async grade(self, essay_text: str, rubric_text: str | None, grade_level: str) -> GradingResult:
     a. Build system_prompt via build_system_prompt(grade_level, rubric_text).
     b. Build user_prompt via build_user_prompt(essay_text).
     c. Build json_schema via build_grading_schema().
     d. Call self._llm.complete(system_prompt, user_prompt, json_schema).
     e. Parse JSON response. On json.JSONDecodeError, retry once with same params. On second failure, raise ValueError("LLM returned invalid JSON after retry").
     f. Validate the parsed dict has required fields (categories array with name, score, maxScore, etc.).
     g. Compute highlight offsets using compute_highlights(essay_text, parsed_categories).
     h. Build GradingResult:
        - id: str(uuid.uuid4())
        - essay_text: the input essay_text
        - essay_excerpt: essay_text[:100] + "..." if len > 100
        - overall_score: sum of category scores
        - max_score: sum of category max_scores
        - summary: from LLM output
        - categories: list of CategoryScore with computed highlights (not LLM quotes)
        - graded_at: datetime.now(timezone.utc).isoformat()
     i. Return the GradingResult.
