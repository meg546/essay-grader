   - async def extract_pdf_text(file: UploadFile) -> str:
     a. Read file contents with await file.read().
     b. Check size: if len(contents) > 10 * 1024 * 1024, raise HTTPException(413, "PDF file exceeds 10 MB limit").
     c. Create PdfReader(io.BytesIO(contents)).
     d. Extract text from all pages, join with "\n\n".
     e. If len(full_text.strip()) < 50, raise HTTPException(422, "Could not extract sufficient text from PDF. The file may be scanned or image-based. Please paste the text directly instead.").
     f. Return full_text.

   - Create fixture for near-empty PDF (PDF with only whitespace or < 50 chars).
   - Write the behavior tests.
   - Use unittest.mock.AsyncMock for UploadFile.read().

    - test_grade_with_rubric_text: POST /api/grade with rubric_text produces result using that rubric

    - test_grade_level_affects_prompt: POST /api/grade with different grade_level values produces different system prompts (verify via mock)
    - test_grade_default_grade_level: POST /api/grade without grade_level defaults to "college"

  <action>
1. Create backend/app/routes/grading.py:
   - Create router = APIRouter(tags=["grading"]).
   - POST /grade endpoint:
     ```python
     @router.post("/grade")
     async def grade_essay(
         essay_text: str | None = Form(None),
         essay_file: UploadFile | None = File(None),
         rubric_text: str | None = Form(None),
         rubric_file: UploadFile | None = File(None),
         grade_level: str = Form("college"),
         user: User = Depends(get_current_user),
     ):
     ```
   - Validate: if not essay_text and not essay_file, raise HTTPException(422, "Either essay_text or essay_file is required").
   - If essay_file provided, call extract_pdf_text(essay_file) to get essay_text.
   - If rubric_file provided, call extract_pdf_text(rubric_file) to get rubric_text.
   - Create LLM client via get_llm_client(get_settings()).
   - Create GradingService(llm_client).
   - Call await grading_service.grade(essay_text, rubric_text, grade_level).
   - On ValueError (from failed LLM validation), return HTTPException(502, "Model inference failed: {error}").
   - On httpx.ConnectError / httpx.TimeoutException (from LLM client), return HTTPException(503, "Model server unavailable. Check MODEL_ENDPOINT configuration.").
   - Return the GradingResult.

2. Update backend/app/main.py:
   - Import grading from routes.
   - Add api_router.include_router(grading.router).

   - Actually, since the route instantiates the client inline, use monkeypatch on the get_llm_client or get_settings to inject the mock. Alternative: make GradingService a FastAPI dependency. Simplest approach: monkeypatch `app.routes.grading.get_llm_client` to return mock.
