       - `const isSubmitDisabled = essayText.trim() === "" || isGrading` — disabled when empty OR grading in progress

    4. **Create handleSubmit async function:**
       ```
       async function handleSubmit() {
         setIsGrading(true);
         try {
           const result = await gradeEssay({ essayText, rubric: rubricCategories });
           setCurrentResult(result);    // Store FIRST
           addToHistory(result);        // Then add to history
           navigate(`/results/${result.id}`);  // Then navigate (instant, no delay)
         } catch {
           toast.error("Something went wrong. Please try again.");
         } finally {
           setIsGrading(false);
         }
       }
       ```
       CRITICAL ORDER: setCurrentResult -> addToHistory -> navigate. Store result BEFORE navigating to prevent flash of empty state.

    5. **Pass disabled prop to child components:**
       - `<EssayInput disabled={isGrading} />`
       - `<RubricEditor disabled={isGrading} />`

    6. **Update Button with spinner and friendly loading copy (per user locked decisions):**

       ```
       <Button disabled={isSubmitDisabled} size="lg" onClick={handleSubmit}>
         {isGrading ? (
           <>
             <Loader2 className="mr-2 h-4 w-4 animate-spin" />
             Reviewing your work...
           </>
         ) : (
           "Submit for Grading"
         )}
       </Button>
       ```
