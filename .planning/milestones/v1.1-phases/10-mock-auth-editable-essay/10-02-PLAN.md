Modify the results view section (the `if (currentResult)` block) in `src/pages/GradingPage.tsx`:

1. Add re-grading state: `const [isRegrading, setIsRegrading] = useState(false)`

2. Create handleRegrade function (similar pattern to existing handleSubmit):
   ```typescript
   async function handleRegrade() {
     setIsRegrading(true);
     try {
       const result = await gradeEssay({
         essayText,
         rubricFile: rubricFile ?? undefined,
         gradeLevel,
       });
       setCurrentResult(result);
       addToHistory(result);
     } catch {
       toast.error("Re-grading failed. Please try again.");
     } finally {
       setIsRegrading(false);
     }
   }
   ```

3. Add `key={currentResult.id}` to `<HighlightProvider>` to force re-mount when result changes (resets highlight state -- avoids stale tooltips/scroll targets from previous result, per Pitfall 3 in research):
   ```tsx
   <HighlightProvider key={currentResult.id}>
   ```

4. Pass new props to EssayPanel:

   ```tsx
   <EssayPanel result={currentResult} onRegrade={handleRegrade} isRegrading={isRegrading} />
   ```

5. Pass isLoading to FeedbackPanel:
   ```tsx
   <FeedbackPanel result={currentResult} isLoading={isRegrading} />
   ```

Everything else in the results view (header, ColorLegend, grid layout) stays the same. The grading input view (non-results) is unchanged.
