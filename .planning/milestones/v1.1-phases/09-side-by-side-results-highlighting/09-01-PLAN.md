Create `src/lib/highlight-utils.ts` with these exports:

1. **Types:** `TextSegment`, `HighlightSegment`, `Segment` (union), `CategoryColor`.

2. **CATEGORY_COLORS array** — 6 entries with FULL static Tailwind class strings (no dynamic construction to avoid purge issues):
   - Blue: bg-blue-100, bg-blue-200, text-blue-700
   - Purple: bg-purple-100, bg-purple-200, text-purple-700
   - Orange: bg-orange-100, bg-orange-200, text-orange-700
   - Teal: bg-teal-100, bg-teal-200, text-teal-700
   - Pink: bg-pink-100, bg-pink-200, text-pink-700
   - Yellow: bg-yellow-100, bg-yellow-200, text-yellow-700

3. **getCategoryColor(index: number): CategoryColor** — modulo lookup into CATEGORY_COLORS.

4. **buildCategoryColorMap(categories: CategoryScore[]): Map<string, number>** — maps categoryId to its index.

5. **getAllHighlights(categories: CategoryScore[]): HighlightRange[]** — flatMap all category highlights, sorted by start offset.

6. **buildSegments(essayText, highlights, disabledCategories)** — converts essay text + highlight ranges into ordered Segment array. IMPORTANT: The mock data contains 3 cross-category overlapping highlights (confirmed in 07-01-SUMMARY). Handle overlaps by giving priority to the first highlight encountered (by start offset, then by order in array). If a highlight's start is before the cursor (because a previous highlight already covered that range), skip it or truncate it to start from cursor. Each HighlightSegment gets an `id` of `${categoryId}-${start}` for scroll targeting. Filter out highlights whose categoryId is in disabledCategories before processing.

Create `src/lib/highlight-context.tsx` with:

1. **HighlightContextValue interface** with: `activeCategoryId: string | null`, `setActiveCategoryId`, `disabledCategories: Set<string>`, `toggleCategory`, `scrollTarget: string | null`, `setScrollTarget`.

2. **HighlightProvider** — wraps children with context, manages state via useState. `toggleCategory` uses functional update on Set.

3. **useHighlightContext** — throws descriptive error if used outside provider.

Import types from `@/api/types`. Use `createContext`, `useContext`, `useState`, `useCallback` from React.

Create `src/components/results/HighlightedEssay.tsx`:

- Props: `{ result: GradingResult }`.
- Uses `useHighlightContext()` for `activeCategoryId`, `setActiveCategoryId`, `disabledCategories`, `scrollTarget`, `setScrollTarget`.
- Computes `colorMap` via `useMemo(() => buildCategoryColorMap(result.categories))`.
- Computes `allHighlights` via `useMemo(() => getAllHighlights(result.categories))`.
- Computes `segments` via `useMemo(() => buildSegments(result.essayText, allHighlights, disabledCategories))` — depends on `disabledCategories` so segments rebuild when toggles change.
- `useEffect` watching `scrollTarget`: when non-null, find element by `id="hl-${scrollTarget}"`, call `scrollIntoView({ behavior: "smooth", block: "center" })`, then `setScrollTarget(null)`.
- Renders a `div.whitespace-pre-wrap.text-sm.leading-relaxed` containing mapped segments:
  - TextSegment: plain `<span key={i}>`.
  - HighlightSegment: `<mark>` with `id="hl-${seg.id}"`, `data-category-id={seg.categoryId}`, classes from `getCategoryColor(colorMap.get(seg.categoryId) ?? 0)`: always apply `.bg`, apply `.bgActive` when `activeCategoryId === seg.categoryId`, apply `opacity-30` when `activeCategoryId !== null && activeCategoryId !== seg.categoryId`. Add `rounded-sm px-0.5 transition-all duration-200 cursor-pointer`. Attach `onMouseEnter` -> `setActiveCategoryId(seg.categoryId)`, `onMouseLeave` -> `setActiveCategoryId(null)`.

  - When disabled: add `opacity-40 line-through`.
  - Icon: `Eye` when enabled, `EyeOff` when disabled (from lucide-react), `h-3 w-3`.
  - Label: `cat.name`.
